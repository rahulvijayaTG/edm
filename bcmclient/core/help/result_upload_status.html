The View Upload Status search results container has the following:

  • Report Id
  • Template Name
  • Report Time
  • Progress
  • Total Records
  • Errors
  • Purged

 

To search
  1. Select the Upload report  by clicking the radio button beside it. Click Purge to remove those templates denoted with Completed tag in the progress column. 
  2. To re-process the incomplete upload status, select a report by clicking on the radio button and click Reprocess.
  3. Click the hyper linked Upload Number to view its Upload Status and errors.

The Reprocess button will be enabled, only if the selected Report is in “Completed with gaps” state.
