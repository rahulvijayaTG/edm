The Local Upload function allows you to specify the file from your local machine.

 To upload data 
  1. Click Browse and fetch an valid .xml file from your local system. Click Upload to upload to the file to the assigned upload base directory. 
    Note: The Local Upload option provides the capability to specify the upload file format
  2. Click Template Details to view the template information
  3. Click Upload to Upload the 

Once the user clicks Upload to upload the contents of the selected file, the system carries out the validations. These validations include data integrity validations (for example, primary key duplication) and user-defined validations.
