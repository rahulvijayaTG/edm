Manage Time Hierarchy

The Time Hierarchy feature allows you to define time as a dimension and create relationships among the components of a time hierarchy. Time hierarchy can be internally generated because it is based on calendar definitions.

 What you can do

Creating Time Hierarchy

  1. Select Manage Hierarchy > Manage Time Hierarchy. 

The HorizonReferenceMaster Result page is displayed.

  1. Click on Create button. 
  2. The HorizonReferenceMaster Add page is displayed.
  3. Enter the Name, Description, Category, Sub Category and effective Start and End Dates. 
  4. Click Save. The HorizonReferenceMaster Edit page is displayed for further modifications. Make any changes required and click Save and Return. Click the Cancel button to abort the activity and return to the previous page without saving any changes. 

Viewing/Editing the Time Hierarchy Details

  1. Select the specific time hierarchy record from the HorizonReferenceMaster and click Details button to view the details of the time hierarchy.
  2. To edit the details of a time hierarchy, select the time hierarchy from the HorizonReferenceMaster and click the Edit button.
  3. You can modify the details in the HorizonReferenceMaster Edit page. Click Save and Return.

Deleting a Time Hierarchy

  1. From the HorizonMasterResult page, select the time hierarchy and click the Delete button. You are prompted for confirmation.
  2. Click Yes to delete the specific record. You can delete a record only if you have deleted the details of that time hierarchy.
