Table Editor - Add Screen

The Add Screen helps you to create new 'Entity' details. 

 What you can do

Create 'Entity' Details

  1. In the Table Editor, you must have clicked on the Create button.
  2. The <Entity> Add screen is displayed.
  3. Enter appropriate values in all the fields and click on the Save button to add the new <Entity> details to the Data Table.
  4. Click the Save and Return button to add the new <Entity> details to the Data Table and return to the Table Editor screen.

Note: The mandatory fields are marked with a red asterisk (*)
