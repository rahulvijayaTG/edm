PIPO Relations

You can add PIPO relations using this screen.

 What you can do

Search for PIPO Relations

  1. In the Navigation Pad, you must have clicked on the Manage PIPO > PIPO link to view the current screen. You can see the existing relationships that are already defined in the system.
  2. The PIPO Relations screen is displayed. Here, you can perform a search based on the PIPO Setup Name, PIPO Setup Description, Name, Description, Status, Effective Start Date.
  3. Enter appropriate values in the required search fields and click on  Search button.
Note: You can also perform a search by specifying a valid wildcard character (*) in any of the search fields. This will retrieve all the available  records in the system.
  1. All the records that match the search parameters that you specified will be displayed.

Adding PIPO relations

  1. To add a PIPO Relation, click the Add button from the PIPO Relations page.
  2. The resulting screen shows the list of existing setups in the system. You have to select one of the setups that will be used as a template for defining the relationship. The setup identifies the primary product dimension level and other dimensions and levels involved in this phase-in/phase-out. You can view the details of the setup by clicking Details button. Search for a PIPO Setup or select a PIPO setup that is displayed and click Next. 
  3. The resulting screen shows the list of members from which the user can select a phase-out member. The members that are shown here are from the phase-in/ phase-out dimension and level defined in the setup. Only members from this dimension and level are shown. Select the member to be phased out and click Next.
  4. The resulting screen shows the list of members from which the user can select the phase-in member. The members that are shown here are from the phase-in/phase-out dimension and level defined in the setup. Only members from this dimension and level are shown. Select the member to be phased in and click Next.
  5. The next screen shows a list of members from the other dimension.

There are 3 options for selecting the members.

  1. If you select the Select All Members option in the top pane, then all the members from that dimension and at that level are selected. Due to pagination, all the members at that level are not displayed in the same page.
  2. If you select the option at the column header level in the table, then it selects all the members displayed in the current page. It is the same as selecting each member in the current page.
  3. If you select any one option, then only that particular member is selected.

Select the member and click on Next.

  1. Enter the Name, Description, Start Date, and End Date in the Set Date page. This Set Date page allows you to define a name and description for the phase-in/ phase-out relationship. You have to define a start date which is the phase-in/ phase-out date. Now the phase-in date and phase-out date map to the Start Date. The End Date field is not being utilized and is more for reporting purposes.
  2. Click on Save And Return.
