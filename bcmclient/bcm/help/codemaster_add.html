Add Code Master

It is always recommended that you review the current code type list prior to adding a new code. This is to ensure that types are not duplicated.

The Add New container is only available after you have performed a search.

 To add a Code Type,
The Add New container header names the code type to which you are adding.

  1. In the Add New container of the Editable Codes tab container, enter the Name of the new code type.


  2. Enter the text that will show in the application in the Display Text field.
    Text should be entered as a string. White spaces are unacceptable. Characters can be lower or upper case.
  3. Click Add. If successful, at the top of the container, a confirmation message displays and the new code in the Search Results container.
You have the option to perform the following tasks:
  • Continue adding Code Types
  • Edit a Code Type
  • Delete a Code Type
