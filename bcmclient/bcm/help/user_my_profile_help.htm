User Profile

The User details screen displays the various fields or information associated with the particular user. The user can choose to modify his profile with the help of the update option.

 The user profile screen has the following features
  1. To modify the details,
    • Fill in the required modified details
    • Click on the update option.
    • This will update/modify the user details as per the changes made.

  2. To reset the user details screen
    • Click on the reset option
    • This will clear the user details screen and all the information in the concerned fields can be entered afresh to save as new

  3. To change the password, click on Change password . This will open a screen which will guide the user through the change of password.
