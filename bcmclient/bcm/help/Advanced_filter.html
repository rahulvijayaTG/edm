Using the Advanced Filter

The Advanced Filter feature helps you to perform a more granular search. Using this feature, you can specify complex filters (search parameters), which can be applied to the supported activities, saved, and invoked by name, at a later time.

Advanced filters are specific to a particular activity. If you have previously defined advanced filters for a particular activity, a list of available advanced filters will appear when you click this icon. You can select the required filter and apply it to the search activity.

Note: Normally, Filters are saved by the user currently logged into MDM. Unless a Filter has been marked as Global, it will be visible only to the user who created it.

  What you can do

Performing a Search using the Advanced Filter option

  1. In the Results page, click the Advanced filter option on the top right corner of the screen.
    The Filter Expression page is displayed.
  2. The Filter Expression page has the following areas:
    • Properties of the Table: Select the required Item property in this area.
    • Filter Description: Specify the Filter description in this area.
    • Expression Editor: The current state of the filter expression is displayed in this area.

Filter constraints can be placed on available properties (fields) for the current activity, such as managing items. For example, you can create an advanced filter for Item ID such that Item ID is displayed only when it has values DIE* or RW*.
To create this advanced filter,

  1. In the Properties of the Table area, select Item.ItemID.
    This value is displayed in the Field Name field of the Filter Description area.
  2. In the Filter Value field of the Filter Description area, type DIE*.
  3. Click OR.
  4. Repeat Step 1.
  5. In the Filter Value field of the Filter Description area, type RW*.
  6. Click OK.

    The advanced filter will now display Item IDs beginning with DIE* or RW* only. The available constraints are =, <>, <, >, <=, >=, like. Complex Boolean expressions can be constructed by combining field constraints with the AND and OR buttons. Parentheses are provided to allow proper nesting of constraints.

  7. Click the Undo button to remove the last addition to the Expression.
  8. Click the Clear button to clear the entire filer expression.
  9. The Cancel button returns to the original activity display (results list) or, if filters have already been created and saved, it returns to the list of existing filters for this activity.
  10. Click the Apply and Return button.
  11. Specify a name for the filter and click the Save Filter icon.
    The filter is created.
  12. To categorize the new filter as Global, select the Global option.
