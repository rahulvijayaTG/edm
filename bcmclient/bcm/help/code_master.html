Code Master

This page helps you to view all the values, of a selected code type (drop-down lists), available in the application. You can also modify code type values, add new values to the selected code type, and/or delete existing ones, from here.

 

 What you can do

Performing a Search

You can perform a search for the required Code Type using either the Simple Search or the Advanced Search feature.

The Simple Search

  1. In the Navigation Pad, click on the Code Master > Manage Code Master. 

  2. The Code Master page is displayed.

  3. The Simple Search feature is displayed by default.

  4. In the Type drop-down list, select the required value and click on the Search button.

The Advanced Search 

  1. To perform an advanced search of the Code Type, click on the Advanced Search link.

  2. This provides an additional search parameter - Name.

  3. Enter a valid code type name in this field, and click on the Search button.

  4. The search results matching the parameter (s) you had specified, are displayed in the Search Results section, at the bottom of the page.

Note: The Advanced Search field is case-sensitive.

 Adding a New Code Type Value

  1. When you click on the Search button, the Code Master page displays two additional sections - Add New <Code Master Value>, and the Search Results section.

  2. In the Add New <Code Master Value> section of the page, enter a name for the new value in the Name field.

  3. Click on the Add button.

  4. The new value will now be displayed in the search results section.

Modifying Code Master Values

  1. In the Search Results section, select the check box (es) corresponding to the code master values that you want to modify.

  2. Make the required changes in the Name and Description columns for these selected values.

  3. Click on the Update button.

Deleting Code Master Values

  1. In the Search Results section, select the check box (es) corresponding to the code master values that you want to delete.

  2. Click on the Delete button.

  3. The page is reloaded with the modified set of values.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the page.
