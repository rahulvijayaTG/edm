Yield Calendar

This page helps you to add and associate a new yield calendar to the selected Operation.

 What you can do

Create and Add New Yield Calendar

  1. In the Assigned Resources tab of the Operation Details page, click the Yield Calendar button to view the Yield Calendar page.
  2. The Yield Calendar page has three sections.
  3. The Operation Yield Calendar section displays the selected Operation details as read-only fields.
  4. In the Yield Calendar Entry section, enter an appropriate Start Date (in mm/dd/yyyy format), for the new Yield Calendar that you are adding. Alternatively, click the Calendar icon () to view the pop-up calendar and select the required date.
  5. In the Yield field, enter an appropriate yield value. 
    Note:  The Yield value should be between 0 and 1.
  6. In the Comments field, enter a brief comment for the yield calendar entry.
  7. Click the Add button.
  8. The Yield Calendar Details section will display the new yield calendar record.

Note: To add another yield calendar, click the Add button again and follow the steps as mentioned above.

  1. Click the Return button to return to the Operation Details page.
  2. To delete an existing yield calendar, select the check box corresponding to that calendar record and click the Delete button.

Editing Yield Calendars

  1. In the Yield Calendar Details section of this page, select the check box corresponding to the calendar record that you want to edit.
  2. Make the necessary change in the Yield column for that particular calendar record.
  3. In the Comments field, modify the comments if required.
  4. Click the Update button to save the changes.
  5. Click the Return button to go back to the Operation Details page.
  6. To delete a calendar, select that record and click the Delete button.
