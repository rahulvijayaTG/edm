Create/Copy Scenarios

The Scenarios –Create Scenarios screen helps you to create a scenario by clicking on the Create button.

In order to use the Scenario Management function the only pre-requisite is the availability of a BASE DATA. So a base data scenario must be created. This base data scenario is used as a reference to set context for the scenarios.

  What you can do

Creating a Scenario

  1. Enter the scenario name in the Name field.

  2. Enter the Scenario description in the Description field.

  3. Click on the Save button to save the scenario.

Copying a Scenario

  1. Enter the Name field to define the scenario.

  2. Enter an appropriate scenario description in the Description field.

  3. Click on the Save button to save the scenario.
