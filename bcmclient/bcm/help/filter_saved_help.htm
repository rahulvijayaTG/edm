List of Filter Expressions

The advanced filter option is used for performing a more complex search, with more specifications. The use of logical AND and OR symbols helps the user define the search to a better degree of accuracy, thereby reducing the time required to perform a search.The screen gives a list of all the advanced filter expressions that the user has saved.

  The following operations can be performed on the screen.
  1. To create a new expression select the Create option. This will take the user to the filter expression editor screen.
  2. To edit an existing filter expression, select the Edit option after selecting the desired expression by clicking on the corresponding radio button. This will again take the user to Expression Editor screen.
  3. To delete an existing filter expression, select the Remove option after selecting the desired expression by clicking on the corresponding radio button. This will delete the expression.
  4. The Cancel option returns the user to the original search screen.
  5. To save a newly created expression, click on Apply and Return option. The original search screen with the selected records appears.
