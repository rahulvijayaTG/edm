Select Member Hierarchy

The Member Hierarchy feature in MDM captures the relationships among all the members participating in the Hierarchy. Every member in the hierarchy will have a 'Parent' member (except the Root node in the tree structure), and 'Children' (except for the Leaf nodes in the tree structure).

A member can be linked to different Parents, but at the same level. You must first delink the association of the existing Parent before linking the member to a different Parent.

Note: In the Member Hierarchy feature of MDM, you cannot add a Level above any of the existing Levels.

 What you can do

Selecting a Member Hierarchy

  1. In the navigation Pad, click the Tasks > Manage Hierarchy > Manage Member Hierarchy link to view the current page.
  2. In the Select Member Hierarchy page that is displayed, select an appropriate Dimension from the drop-down list, and click the Show Hierarchy button.
  3. The Manage Member Hierarchy field that is displayed, lists all the available hierarchies for the selected Dimension.
  4. Here, select the required Member Hierarchy from the drop-down list, and click the Manage Member Hierarchy button.
  5. The Manage Member Hierarchy page that is displayed helps you to view the hierarchy details, and also edit the parent-child relationships at each hierarchy level, if required.
