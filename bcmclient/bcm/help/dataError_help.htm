Date Errors Page

The Data Errors Page shows a report of the erroneous data loaded into the system as part of the operational data load workflow.

  What you can do
  1. You can perform a search for Errors, based on the Entity name.
  2. Enter the required Entity Name in the search field, and click on the Search button.
  3. The search results table will display all the error records that match the search parameter that you had specified.

Note: Alternately, you can also perform a wildcard character search (by specifying * in the search field). This will retrieve all the available error records in the system.

  1. To view the error details, click on the required Entity Name link. The selected error document details are displayed in the Error Report page.
