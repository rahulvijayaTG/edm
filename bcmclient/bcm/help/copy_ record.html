Copy Record

The Copy feature allows you to copy an existing record in the data table and create a new one with the same field values as that of the original. This feature is helpful while creating a new entity that closely resembles another, reducing the cumbersome creation process to just one click.
  What you can do

Copying an Existing Record to Create a New Record

  1. Select the check box corresponding to the record that you want to copy.
  2. Click on the Copy button.
  3. The Add <Feature> page is displayed, listing all the field values of the original record, but with a system-specified ID.
  4. Specify a unique value in the ID field (marked with a key symbol) for the new record, and click on Save, to update the changes.

Note: If you have not selected any record, or have selected more than one record, and attempt to perform the Copy function, the system will display a warning message asking you to make the necessary changes before copying.

  1. Ensure the values in all the fields of the new record are as required; make modification if necessary, and click on the Save and Return button to go back to the 'table editor view' page.
  2. To abort the copy function, click on the Cancel button. This will return you to the 'table editor view' page, without saving the new record.
