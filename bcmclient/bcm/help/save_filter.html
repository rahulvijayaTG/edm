Save Filter

The Save filter option is used to save a particular filter expression you the user would like to use in future

  What you can do

Saving a Filter Expression

  1. Click on the Advanced Filter icon () on the top-right corner of the screen.
  2. The Location links screen is displayed.
  3. Create the required filter expression, and click on the Apply and Return button.
  4. Now you can view the original table. By specifying a name for the filter specification, and clicking on Save filter icon, the filter expression is stored for future use.
