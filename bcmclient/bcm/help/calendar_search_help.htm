Calendar Search Page

Calendars provide a mechanism to specify time dependencies for entities (location, resources, and distribution lanes) in the supply chain. The Calendar management feature of MDM helps you to create and manage three calendar types: resource calendar, location calendar and distribution lane (DL) calendar.

Calendars help you allocate a series of regular time periods to each entity. The Calendar management tool provides a method for defining the regular series of time periods, to which, variable parameter values can be assigned. 

For example, a calendar can provide a different value for the same variable, each day, or each week. This page displays all the three types of calendars. You can apply the appropriate Filters to view the calendar of interest. 

To view the Calendar details, click on the required Calendar Name link.

 What you can do

Performing a Calendar Search

  1. In the Calendar Search page that is displayed, enter the search criteria in the requires text field provided under each column heading.

  2. Click on the Search button.

  3. The search results based on the criteria that you had specified are displayed.

Note: To choose an existing Calendar record,  select the check box corresponding to the required Calendar, and click on the Select button.

Exporting Calendar Details

  1. To export Calendar details onto an excel spreadsheet, select the check box (es) corresponding to the required Calendar Name (s).
  2. Click on the Export to Excel button.
  3. The File Download dialog box is displayed.
  4. To open the selected Calendar details in an excel spreadsheet, click on Open.
  5. To save the selected Calendar  details in an excel spreadsheet, click on Save.
  6. in the Explorer dialog box that is displayed, specify the destination, and click on Save.

Viewing/Editing Calendar Details

  1. To view/edit Calendar Record details, click on the required Calendar Name link.

  2. The Calendar Details page displays the selected Calendar details.

  3. Make the required changes and save the calendar record.

Creating a New Calendar

  1. To create a new Calendar record, click on the Create button.

  2. The Create Calendar Details page is displayed.

Deleting a Calendar Record

  1. To delete an existing calendar record (s), select the check box (es) corresponding to the record (s) that you want to delete.

  2. Click on the Delete button.

Note: To abort any activity in this page, click on the Cancel button, return to the Edit Resource page.
         To clear the search filters that you have specified, click on the Clear button.
