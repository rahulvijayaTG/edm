Edit Code Master

Periodically, the need may arise to edit a code type entry. This may arise due to a spelling error or having a code type that is too broad or ambiguous. The edit task is performed in the search results container.

The Search Results container is only available after you have performed a search.

 To edit a Code Type,
  1. In the Search Results container of the Editable Codes tab container, click the checkbox(s) next to the type details that you are modifying.
  2. Enter the changes into the Name field.

    3. Text should be entered as a string. White spaces are unacceptable. Characters can be lower or upper case
  • Click Update. If successful, at the top of the container, a confirmation message displays.
    • You have the option to perform the following tasks:
    • Edit a Code Type
    • Add Code Types
    • Delete a Code Type
