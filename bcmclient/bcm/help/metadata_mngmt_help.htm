Metadata Management

 What you can do

Search for all Metadata Objects

  1. In the Search Metadata page, the following metadata objects are used for metadata search and results:

    • Data Package which maps to a Service 

    • Data Group which maps to a Table 

    • Data Element which maps to a Field

    • Business Rule

  2. In the Search Metadata screen,

    • In the Search String field, give % as the search string. 

           or

    • Type Search String as any exact Entity Name, check the Exact Match and Case Sensitive boxes and click on Search. 

           or

    • Type partially matching search string and click Search.

    The Metadata search results page is displayed.

Search for each Metadata Object

  1. In the Search Metadata page, Uncheck all options except Data Package.

  2. Type % as search string and click Search.

    The Metadata Search Results page is displayed.

  3. For a specific Entity name search, type the required Entity name in the Search String field and check the Exact Match and Case Sensitive check box.

Note: Execute similar searches individually for Data Group, Data Element and Business Rules, one option checked at a time. Use relevant search strings for that particular metadata object.

 

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the page.
