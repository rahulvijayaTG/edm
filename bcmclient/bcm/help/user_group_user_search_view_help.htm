User Group - View Users

The View User Group Users screen displays a list of all the existing users, for the selected User Group. You can also perform a search for particular user records, using the Simple Search and/or the Advanced Search features.

 What you can do

View Users for the Selected Group

  1. This screen when displayed, lists all the existing users for the selected User Group in the Search Results table.

  2. You can view the following user details from this table:

Field Description
Login Name Displays the User's Login Name. Click on the required User Login Name link to view that User's details.
First Name Displays the User's first name.
Last Name Displays the User's second name.
Email Address Displays the User's email address.
User Group Displays the group that a user belongs to.
Organization Name Displays the organization name that a user belongs to.
Status Displays the User status.
Role Displays the User's role.

  1. Click on the Done button to return to the selected User Group Profile screen.

Performing a Search for Users

  1. You can perform a search for the required user records, within the displayed users list, using the Simple and/or Advanced Search features.

  2. The Simple Search feature provides the following search filters:

Field Description
Login Name Enter a valid user login name. You can perform a search on this filter, by entering a wildcard character. For example, "bp*", which will search and retrieve all those records that have a login name starting with "bp".
Show Inactive Select this check box if you want the search results to list only the Inactive users.

  1. You can also click on the Advanced Search link to perform a search. This feature provides additional search filters that you can specify, to achieve a more granular result.  The additional search filters displayed in the Advanced Search feature are as follows:

Field Description
Role Select the required role from the drop-down list.
First Name Enter a first name.
Last Name Enter a last name.

Note: You can perform a search by specifying a wildcard character in all input fields.

  1. Click on the Search button.

  2. The search results that match the filters you had specified, are displayed in the Search Results table.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the screen.
