Delete Code Master

If a code is no longer used by the system, it may be deleted from the current code type list. It is recommended that you perform this task periodically for proper maintenance of the system.

The delete function is only available after you have performed a search.

 To delete a Code Type,

  1. In the Search Results container of the Editable Codes tab container, click the checkbox(s) next to the type details that you are removing.


  2. Click Delete. If successful, at the top of the container, a confirmation message displays. If you remove an entry in error, there is no "undo". The entry must be re-entered in the system using the Add New container.
You have the option to perform the following tasks:
  • Continue adding Code Types
  • Edit a Code Type
  • Add a Code Type
