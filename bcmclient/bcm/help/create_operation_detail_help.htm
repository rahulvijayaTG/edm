Operation Details

The Create Operation Details page helps you to add new operation details. All mandatory fields are marked with a red asterisk (*). 

 What you can do

Create New Operation Details

  1. Click the Create button in the Operations Search page to view the current page.
  2. The create Operations Details page displays a system-generated Operation Name. Enter a unique Operation Name in this field.
  3. Enter a Location ID for the new Operation record. You can also select the required Location ID by clicking on the icon () displayed next to the field.
  4. Select an appropriate Operation Class from the drop-down list.
  5. The Operation Details page is made up of two tabs - General and Assigned Resources.
  6. Enter the classification and manufacturing details for the new Operation Record, in the General tab.
  7. Click the Assign BOR button, to select a BOR.
  8. In the BOR Search page that is displayed, select the radio button corresponding to the BOR Name that you want to assign, and click on the Select button.
  9. This page also allows you to Override the Rate, Yield, and Average Cycle Time attributes of the selected Item.

Note: You can also modify the Rate, Yield and Average Cycle Time details in the Operations Details page (without clicking on the Override button), by changing the values in the respective fields. But, these changes will be specific to the selected operation only. If you want to modify these attributes at the Item level, click on the Override button and make the required changes.
