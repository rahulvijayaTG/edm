Creating a New Measure

For creating a new measure or duplicating a measure, the Name field must be open for edit.

 

 What you can do

Renaming a measure

  1. For an existing measure, the Name field is locked to prevent accidental changes. 
  2. Unlock the field by clicking on the lock icon, make the change and click on Save button to commit the change to the database. 

Note: A SinglePoint or Bi-Directional measure in Demand Manager can support only ‘Double’ data type in the database and both these type of measures need appropriate data storage specifiers i.e., ‘Data Length’ and ‘Precision’ fields to have a valid value. A comment type measure in Demand Manager only supports String type data.

  1. If your SinglePoint or Bi-Directional measure needs to capture both negative and positive values, select “NEGATIVE” for data range. You can override the system’s default behavior of measure grouping by specifying a unique value for “InMem Cube” or let the system automatically group the measure based on its properties.
  2. Every database measure requires the “External Source” property to be populated. If you want to create a temporary SinglePoint or Bi-Directional measure then do not select a value.
