Edit Records

The Edit button in the table editor helps you to modify one or more selected rows of the MDM data table. 

The Edit function differs from Mass Edit in that, with mass edit, one value (for a particular field) is updated across all records being mass edited, while editing helps you to modify a field value for the individual record selected. 

Note: You can edit multiple records using the Edit button only from the Table Editor. All the records selected for Editing are displayed as columns. If there are more records than can fit horizontally, a scroll bar is provided.

  What you can do

Editing Item Details

  1. Click the radio button corresponding to the item/record that you want to edit.
  2. Click the Edit button. The Edit Item/record Details page is displayed.
  3. Make the required changes in the fields and click the Save and Return button.
