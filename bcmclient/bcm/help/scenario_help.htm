Maintain Scenarios

The Scenario Workflows help you to explore, understand, and develop the “what-if” scenarios that can be generated by modifying underlying parameters that influence the calculation of inventory targets. This capability can help inventory planners learn and understand their supply chains better, and to effect business changes in light of a well-defined inventory strategy.

The Maintain Scenarios page allows you to Create/Copy/Delete/Set Context/Search scenarios. 

In the Navigation pad, go to > Tasks > Scenario Management > Maintain Scenarios. The page displays a selectable tabular view of scenarios. You can select only one scenario at a time.

Note: To perform any Scenario Management functions, you must have a baseline scenario called "Base_data", in your system.

  What you can do

 

Create/Copy/Search/Delete Scenarios

  1. In the navigation pad, go to Scenario Management > Maintain Scenarios.

  2. The maintain Scenario page is displayed. You can  Create, Copy, Delete, Set Context, and Search Scenarios from this page.

  3. To create a scenario as a copy of the Base Data, click the Create button.

  4. To copy a scenario, select a parent scenario.  Now, select the radio button corresponding to this parent scenario and click the Copy button.

  5. To delete a scenario, select the option corresponding to the scenario to be deleted, and click the Delete button.

  6. Click the Save button to update the changes. Every time a scenario is modified, the (refresh) icon is displayed for that particular scenario. You must click the Refresh icon to reflect the changes.

  7. All the edits are performed only on the scenarios that are put in context. To set the context of scenario, select the check box corresponding to that scenario, and click on the Set Current Scenario button. If you select a scenario other than the Base Data scenario, the page header will display your username and the name of that scenario.

  8. To perform a scenario search, select filter settings above the scenarios list and click the Search button.

  9. To clear the values that you have specified in the search filters, click the Clear button.

  10. To add a log comment for the scenario in context, click the Scenario Log icon.

  11. To refresh the scenario list, click the Refresh icon.

  12. To print the scenario list, click the Print icon.
