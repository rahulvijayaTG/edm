Audit Trail

An Audit Trail enables changes to the document instance (database table) to be tracked. You can construct the document change history from the Audit Trail information. Every operation performed by a user is logged into the corresponding Audit Trail Table and provides comprehensive details about that operation. 

Audit Trail tables have the following information about the operations performed by users logged in: 

  • Addition of Data
  • Modification of Data 
  • Date of Operation
 What you can do

Performing a Search

You can search for records, based on various search criteria.

To access audit trail tables,

  1. Click the Tasks > View Tables > Audit Trail Tables link. 

Note: You can access the Audit Trail Tables only if you have System Administration privileges. You will not see this link if you are a normal user of MDM. When you click the Audit Trail Tables link, all the tables (in the database) that have the Audit Trail feature enabled are displayed. 

  1. Click the required Audit Trail Table link to monitor the activity details.
  2. Type the required values (search parameters) in the search fields. 
  3. Click the Search icon. 

Note: The search results are displayed, based on the parameters specified. To remove the values specified in the search fields, click the Clear button. 

  1. To save a filter expression created, click the Save Filter icon. 
  2. To use the advanced filter option, click the Advanced Filter icon. 
  3. If there are more than ten records that match the specified search parameters, they will be listed in subsequent pages. You can browse through these pages by clicking on the appropriate navigation button (displayed at the bottom of the page).

Exporting table data

You can export table data to an MS-Excel spreadsheet.

To export data to a spreadsheet,

  1. Select the check box (es) corresponding to the required record (s).
  2. Click on the Export to Excel button.
  3. The File Download dialog box is displayed.
  4. To open the selected record details in an excel spreadsheet, click on Open.
  5. To save the selected record details in an excel spreadsheet, click on Save.
  6. In the Explorer dialog box that is displayed, specify the destination, and click on Save.
