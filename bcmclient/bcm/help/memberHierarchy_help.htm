Member Hierarchy

The Member Hierarchy page in MDM, helps you to view the selected Member Hierarchy details, and also edit the parent-child relationships at each level of that hierarchy, if required.

 What you can do

Managing Member Hierarchy

  1. In the Select Member Hierarchy page, select a Member Hierarchy and click the Manage Member Hierarchy button to view the Manage Member Hierarchy page.
  2. The Manage Member Hierarchy area has information about the dimension, hierarchy, and current level selected.
  3. The Manage Member Hierarchy page has three areas: 
  • Members At Current Level
  • Child Members
  • Unassigned Members
  1. The root of the selected hierarchy is displayed in the Members At Current Level area. To view the parent members of subsequent levels in the hierarchy, click the Go One Level Down icon or the One Level Up icon. The children of the selected Parent at that level are displayed in the Child Members area.

Note: You can search for the required member (in the Members at Current Level as well as the Child Members areas), by specifying an appropriate value in the corresponding search field and clicking the Search button. You can also use wildcards to search specific members. (by specifying a suitable wildcard character, such as *)

  1. Select the required parent member and click the Show Child button.

The Child Members area lists the child members of the selected member, while members that are not associated with any parent in the hierarchy are listed in the Unassigned Members area.

  1. You can remove an existing child member and/or add a new one to the selected level hierarchy.
  2. To remove an existing member, select that member and click the > button.
  3. To add a new member, select the required member from the Unassigned Members area and click the < button.

You can also add or delete multiple entries by selecting them and clicking the << (Add All) or >> (Delete All) buttons respectively.

  1. Make the necessary changes to the selected member hierarchy record and click the Save button to update the changes. Alternatively, you can also click the Save and Return button to save the changes and return to the Select Member Hierarchy page.
  2. Click the Cancel button to abort the operation and return to the Select Member Hierarchy page without saving the changes.
