Create Record

The Create button in the table editor helps you to add a new record into the MDM data table. In the screen that is displayed, enter the appropriate data in the required fields, for the selected table row. 

Note: The mandatory fields are marked with a red asterisk (*).

 What you can do

Creating a Record

  1. To add a new record to the data table, click on the Create button.

  2. In the screen that is displayed, enter appropriate values in the required fields and click on the Save button. You can also click on the Save and Return button to save the new record entry and return to the 'table editor view' screen.

  3. If at any time, you want to abort the Create process, click on the Cancel button. You will lose all the changes that you made in this screen and return to the 'table editor view' screen.

Note: If you enter an invalid value in any of the mandatory fields, and attempt to save the new record, the system displays a warning message will return to the data entry screen.
