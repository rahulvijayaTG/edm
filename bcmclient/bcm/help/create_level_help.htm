Create Level

The Level Add page helps you to create new Level details.

 What you can do

Create New Level Details

  1. In the Level Search Results page, click the Create button to view the current page.
  2. Enter a unique Level ID in the Level ID field.
  3. Enter the Dimension ID in the Dimension ID field.
  4. Enter a unique name for the level in the Name field.
  5. Enter a brief description of the new Level in the Description field.
  6. Type a unique value in the Logical Table Name field. For e.g, if the Logical Table Name is Item, it’s corresponding Physical Table Name may be MST_ITEM. The Physical Table is present in the database, while the Logical Table is a link to the Physical Table.
  7. Type a unique value in the Logical Column Name field. The Logical Column Name represents the Primary Key Column Name.

Note: All fields in this page are text-only fields. Do not specify any numerical or special characters in any of these fields.

  1. Click on the Save button to save the new Level record in the data table. Alternately, you can also click on the Save and Return button to save the new record, and return to the Level Search Results page.
  2. Click on the Cancel button to abort the `create' activity, and return to the previous page without saving any changes.
