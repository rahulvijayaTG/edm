Add New User details

The Create New User page helps you to enter general information for a new User. The mandatory fields are marked with a red asterisk (*).

Note: The Organization name field is displayed as a read-only label.

 What you can do

Create New User Details

  1. In the Login Name field, specify the login name of the user. 

  2. In the Password field, specify the password for the user. 

  3. In the Verify Password field, re-enter the password mentioned in step 2. 

  4. In the First Name field, type the first name of the user. 

  5. In the Last Name field, type the last name of the user. 

  6. In the Phone and Fax fields, type the telephone number and fax details of the user. 

  7. In the Email Address field, type the email address of the user. 

  8. In the Address1, Address2, and Address3  fields, type the mailing address of the user. 

  9. In the City field, type the city to which the user belongs. 

  10. From the State list, select the state to which the user belongs. 

  11. In the Postal Code field, type the zip code of the user. 

  12. From the Country list, select the country to which the user belongs. 

  13. From the Designation list, select the designation of the user. 

  14. From the Manager list, select the manager of the user. 

  15. From the Absentee list, select the required user who can be assigned the tasks, in this user’s absence. 

  16. From the Locale list, select the local language.

  17. Click the Save button. 

  18. Click the Reset button to undo the changes if needed.

  19. Click on the Cancel button to abort the 'add' operation and return to the User Group Details page.
