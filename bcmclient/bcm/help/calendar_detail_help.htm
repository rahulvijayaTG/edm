Calendar Details Page

The Calendar Details page helps you to view/modify the selected Calendar record details.

 What you can do
Calendar Details

  1. Click on a Calendar Name link in the Calendar Search page to view the current page.

  2. This page helps you to view/modify the selected Calendar details.

  3. You can view/modify the following calendar details:

Field Description
Calendar Name Displays the Calendar name. To modify this field, enter a different, but unique name.
Description Displays a brief description of the calendar. Modify this description, if required.
Category Displays the calendar category. Change the category of the calendar, if required.
Availability UOM Displays the unit of measurement, for the availability of the resource. Change this value by selecting the appropriate UOM from the drop-down list.
Sub Category Displays the calendar sub-category. Change this value if required.
Calendar Type Displays the calendar type. You can modify this value by selecting the appropriate value from the drop-down list.

  1. Click on the Save button to save the changes you have made.

Mass Edit

  1. Select a Start Date and an End Date by clicking on the corresponding date picker tools.

  2. Select the attribute to be updated from the dropdown against Entry Attribute.

  3. Enter a value for the selected attribute against Entry Value.

  4. Click the Mass Update button to update the selected attribute.
Calendar Entry Details

  1. Select a Start Date by clicking on the corresponding date picker tool. Click Apply.

  2. The Fixed Calendar Details along with the total number of records  is displayed.

  3. Enter values in the respective fields and Click Save.
