Create Hierarchy

The Hierarchy Add page helps you to create new Hierarchy details.

 What you can do

Create New Hierarchy Details

  1. In the Hierarchy Search Results page, click the Create button to view the current page.
  2. Enter unique values in the Hierarchy ID, Dimension ID and Name fields.

Note: All fields in this page are text-only field. Do not specify any numerical or special characters in any of these fields.

  1. Enter a brief description of the new Hierarchy, in the Description field.
  2. Click the Save button to save the new Hierarchy record in the data table. Alternately, you can also click on the Save and Return button to save the new record, and return to the Hierarchy Search Results page.
  3. Click the Cancel button to abort the `create' activity and return to the previous page without saving any changes.
