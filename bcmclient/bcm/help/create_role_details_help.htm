Create Role Details

The Create Roles page helps you to add a new Role to the data table. 

 What you can do

Creating New Role Details

  1. In the Manage Roles Search Results page, click the Create link to view this page.
  2. The Role Details page is displayed with the Workflow Role Details and Table Editor Role Details tabs.
  3. Type the Role ID and Role Name in the respective fields.
  4. In the Roles Details page, click the Add Activities button to view the Activity Search page.
  5. In the Workflow Activity Search tab, you can associate workflow activities to the role.
  6. Select the required activity and click the Save button.
  7. Click the Table Editor Search Activity tab.
  8. In the Table Editor Activity Search tab, you can assign permissions for the selected tables.
  9. Select the required Activity and click the Save and Return button to return to the Role Details page.
  10. In the Table Editor Activity Search tab, you can set the following permissions:
    • View - Select this option to view the selected table. You will be able to view the records in the table only if you have enabled the View option.
    • Create - Select this option to create the selected table. You will be able to create records in the table only if you have enabled the Create option.
    • Edit - Select this option to edit the selected table. You will be able to edit records in the table only if you have enabled the Edit option.
    • Delete - Select this option to delete the selected table. You will be able to delete records in the table only if you have enabled the Delete option.
  11. If the displayed list of activities do not meet your requirement, you can perform a search for the specific activity, based on the Activity Name. Enter the required Activity Name in the text box provided, and click on the Search icon/button.
  12. The Role Details page will now display the selected activities for the new role.
  13. To delete an activity, select the check box corresponding to that activity, and click on the Remove Activities button.
  14. Click the Save button to save the new role. Alternately, you can also click the Save and Return button to save the new role and return to the Manage Role Search Results page.
  15. To abort the 'create' activity at any point of time (before saving the details), click the Cancel button.
