Data Audit Report

You can view a Data Audit Report for a particular Entity. 

 What you can do
 

  1. In the Audit Report Filter section, select the following required fields to search:

    • In the Entity field, select the required value(s). These values are the ones for which audit trail has been enabled.

    • In the User field, select the required value(s). 

    • In the Column Filter field, select the required value from the list. 

    • In the Date Range field, type the required date or click on the Date Picker to select the required date. 

    • In the Filter value field, specify a required value.

Note: Column Filter field and Filter Value field are displayed only if the search is for a single entity.

  1. Click Search.

    The Entity name and the row count is displayed in the Audit Report Results section.

  2. Click on the required Entity name and click View Details.

    The Audit Report Details for the selected entity is displayed.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the page.
