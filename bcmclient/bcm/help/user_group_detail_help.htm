User Group Details

The User Group Details page helps you to view/modify the selected User Group details. 

 What you can do

Viewing/Editing User Group Details

  1. Click the required User Group Name link to view the User Group Details page.

  2. This page helps you to view/modify the selected Group details.

  3. The General Information section displays the following details:

Field Description
Group Name Displays the selected Group Name. Modify the name, if required.
Description Displays a brief description of the User group. Modify this description.
Role Details The roles created are displayed in the Available Roles area. Select the required role and click the << or >> button to either add or remove the role from the Assigned Roles area. The user group is saved with the roles defined in the Assigned Roles area.

Note: One user group can comprise of multiple Roles.  
Organization Displays the organization name as a read-only label. You cannot modify this information.
Type Displays the Group type. Select the required Group Type from the drop-down list.
Users The View, Assign, and Add New buttons will be enabled only when you save the user group. Create a new user or assign an existing user to the selected user group. 
  • To view the Users belonging to the selected group, click the View button. The View User Group Users page is displayed, listing all the users for the selected Group. 
  • To assign new users to the selected group, click the Assign button. The User Search - Search Results page is displayed. Select the User(s) to be added to the group and click the Add to Group button.
  • To create new users, click the Add New button. The User Details - General Information page is displayed. Click the Save button to add the new user to the selected user group. The newly created user is automatically added to the user group.

  1. Modify values in the required fields and click the Update button to save the changes.

Assigning a Domain

  1. To assign a business line (domain) to the selected group, click the Assign Domain button.

  2. The Assign Domain page is displayed.

  3. Select the required business line check box and click the Save button.

Activating/Deactivating a Group

  1. If the selected user group is in the 'Inactive' status, the Activate button is displayed. 

  2. Click the Activate button to change its status to 'Active'. A status message confirming the operation is displayed below the User group Details section heading.

  3. To change the group status to 'inactive', click the Deactivate button.

The Save as New Feature

  1. The 'Save as New' feature is very similar to the Copy function.

  2. You can create a new User Group with the same attributes, using this feature.

  3. Enter a unique name in the Group Name field.

  4. Click the Save as New button.

  5. The page is reloaded and the new User Group is displayed, with the same details as that of the originally selected one.
