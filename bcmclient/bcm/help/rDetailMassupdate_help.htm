Mass Update Resource

In this page, you can update the values of the selected records simultaneously.

 What you can do

  1. Select the required properties to be edited. For e.g, select the Category and SubCategory fields.
    Note: Only properties that are selected are updated. If you do not select a property, it is not considered for the mass update operation.

  2. For the selected properties, enter the new value in the field provided. For e.g, In the Category and SubCategory fields, enter suitable values.

  3. Click the Save and Return button to save the changes and return to the Resource Search page.

  4. Click the Cancel button to cancel the mass update operation.
