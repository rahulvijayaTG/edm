Manage Roles

The Manage Roles feature helps you to search, view, edit, and create roles for the MDM users. 

 What you can do

Performing a Role Search

  1. In the Navigation Pad, click the Enterprise Model > Manage Roles link.
  2. The User Role Search page is displayed.
  3. You can perform a Roles search based on two parameters:

  • Role ID: Enter a valid Role ID in this text box.

  • Role Name: Enter a valid Role Name in this text box.

  1. Enter valid data in any/all the above-mentioned fields and click the Search button.
  2. The Search Results table is displayed at the bottom of the page, listing all the roles that match the parameters that you had specified.

Note: You can also perform a search without entering any data in either of these fields. This will retrieve all the available roles in the system.

  1. To view the details of a particular role, click on that Role link in the Search Results table.
  2. To create a new Role, click the Create button.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the page.
