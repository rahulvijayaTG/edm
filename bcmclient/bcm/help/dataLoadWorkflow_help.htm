Data Load Workflow

You may want to load data into the Input Staging Tables before starting up the MDM application. MDM provides CIS Backbus interfaces from TMAPI unconstrained data sources, into the MDM Input Staging tables. Refer to the MDM Installation and Administration Guide for more details.

You may further execute the EndToEnd or Data Load Workflow to propagate the Input Staging dat into MDM. The MDM application provides a CIS Frontbus operation to achieve this. Refer to the MDM Installation and Administration Guide for more details. Alternately, you can also perform the operational workflow from the application UI, through the Data Load Workflow feature of MDM.  

The Data Load Workflow feature of MDM helps you to initiate the process of receiving of data from the client database, comparing the data against some set Rules, and committing this data into the MDM database.

 What you can do

Starting the Data Load Workflow

  1. In the Navigation Pad, you must have clicked on the Data Load Workflow link under Staging > Inbound Staging >Data Load Workflow.
  2. In the Data Load Workflow screen that is displayed, click on the Start Workflow button to initiate this workflow process.
  3. At any time, to abort this process, click on the Cancel button.
