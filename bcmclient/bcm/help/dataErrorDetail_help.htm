Data Error Details Page

The Error Report page displays information regarding each error record for a given table.

  What you can do
  1. The Error Report page displays information regarding each error record for a given table.
  2. It lists the primary keys, the field due to which the error occurred, the validation rule or constraint which failed, and the severity of the error.
  3. Click on the Export to Excel button to download the error details onto an excel spreadsheet.
