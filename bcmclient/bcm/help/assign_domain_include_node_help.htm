User Group Domain Page

By assigning domains, you can provide or restrict specific data to a user. To assign domains, define data hierarchies and include/exclude nodes in the hierarchies for the user group.

The User Group Domain page allows you to assign and restrict access to the required domains (Nodes in the Hierarchy).

A Node is the intersection of Dimension, Hierarchy, and a Level in the hierarchy tree. For example, if MyHierarchy is a hierarchy with the Dimension Time, and is made up of three levels - Year, Month, and Date, and these in turn have the following members:

  • Year - 2003, 2004, and so on.
  • Month - Jan03, Feb03, and so on.
  • Date - Jan0301, Jan0302, and so on.

The Node in the above hierarchy could be MyHierarchy-Year-2003 or MyHierarchy-2003-Feb03-Jan0302. When a Node gets assigned to a User Group, every child of that node gets assigned to that User Group automatically.

Similarly, when a particular node is unassigned (or excluded) from a User Group, every child of that node automatically gets excluded.

 

 What you can do

To assign a domain to a user group

  1. In the User Group Details page, click the Assign Domain button.

    The User Group Domain page is displayed with two tabs, Included Nodes and Excluded Nodes. The Included Nodes tab lists all the nodes in an hierarchy that are accessible to the selected user group.

  2. Select the Included Nodes tab.

    The following information is displayed in the Included Nodes Tab.
