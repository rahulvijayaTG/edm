Resource Alternate tab

The Resource Alternate tab displays a read-only table listing the following details:

Field Description
Alternate Name Displays the Resource Alternate name for the selected resource.
Resource Name Displays the Resource name.
Description Displays a brief description of the Resource Alternate.
Category Displays the category of the Resource Alternate.
Sub-Category Displays the sub-category of the Resource Alternate.
Priority Displays the priority value associated with the Resource Alternate.
Location Displays the Resource Alternate location.
