Level Hierarchy

The LevelHierarchy feature of MDM helps you to arrange the levels to define the parent-child relationships in a hierarchy.

Each level in a LevelHierarchy is given a precedence value (called as Rank in MDM). This Rank provides the depth of each level in an hierarchy, starting at the root.

For example, a level with the precedence `Rank 1', is the root of the hierarchy tree, while the level with `Rank 2', becomes the child of the root.

So, the LevelHierarchy feature helps you to define and capture the parent-child relationships among levels of a hierarchy.

 What you can do

Perform a LevelHierarchy Search

  1. In the Navigation Pad, you must have clicked on the Tasks > Manage Hierarchy > LevelHierarchy link to view the current screen.
  2. The LevelHierarchy Search screen is displayed. Here, you can perform a search based on the Hierarchy ID, Level ID, Logical Column Name, Rank, Modified Date, and so on.
  3. In the Search Results table, enter appropriate values in the required search fields and click on the Search icon ().
Note: You can also perform a search by specifying a valid wildcard character (*) in any of the search fields. This will retrieve all the available LevelHierarchy records in the system.
  1. All the records that match the search parameter that you specified will be displayed.
  2. To remove a particular levelhierarchy record from the data table, select the check box corresponding to that record, and click on the Delete button. The Results screen will be reloaded with the new result set.

Exporting table data

  1. To export a Levelhierarchy record onto an excel spreadsheet, select the check box (es) corresponding to the required Levelhierarchy record (s).
  2. Click on the Export to Excel button.
  3. The File Download dialog box is displayed.
  4. To open the selected Levelhierarchy details in an excel spreadsheet, click on Open.
  5. To save the selected Levelhierarchy details in an excel spreadsheet, click on Save.
  6. In the Explorer dialog box that is displayed, specify the destination, and click on Save.

Updating Records

To modify and update one or more fields, common across the set of records in the table, select the check boxes corresponding to those records and click on the Mass update button.

Creating a new Record

  1. To create a new record, click on the Create button.

  2. The Levelhierarchy Add screen is displayed.

Copying Existing Record Details

  1. To create a new Levelhierarchy record, in the data table, based on the field values of an existing record, select the check box corresponding to that record.

  2. Click on the Copy button.

Modifying Record Details

  1. To modify Levelhierarchy details in a data table, select the check box corresponding to the required Record.

  2. Click on the Edit button.

  3. The Levelhierarchy Edit screen is displayed.

Deleting Records 

  1. To delete a Levelhierarchy record from an MDM table, select the check box corresponding to the required record.
  2. Click on the Delete button.
  3. The selected record is deleted and the table editor will be reloaded to display the updated list of records.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the screen.
