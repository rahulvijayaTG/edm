Table Editor Screen

The table editor screen helps you to perform various operations, including creating, copying, modifying, deleting, updating and exporting of data. You can also browse through the records, using the navigation controls (first, previous, next, last, and the Jump button) displayed at the bottom-left of the screen. Furthermore, you can customize the table editors (hide, sort and freeze columns, re-order fields) and create favorites on the user interface.

This screen also allows you to perform a search based on various parameters. You can also perform a search by specifying a fully qualified Item/Resource/Location name, or a suitable wildcard specification such as “bp*”; a list of all matching records that match the search criteria, will be displayed in the Search Results section. 

Note: If you perform a search without specifying any search parameters, the search results will list all the available records in the system.
 What you can do

Exporting table data

  1. To export item/location details onto an excel spreadsheet, select the check box (es) corresponding to the required Item/Location ID (s).
  2. Click the Export to Excel button.
  3. The File Download dialog box is displayed.
  4. To open the selected item/location details in an excel spreadsheet, click on Open.
  5. To save the selected Item/Location details in an excel spreadsheet, click on Save.
  6. In the Explorer dialog box that is displayed, specify the destination, and click on Save.

Updating Records

To modify and update one or more fields, common across the set of records in the table, select the check boxes corresponding to those records and click on the Mass update button.

Creating a new Record

  1. To create a new record, click on the Create button.

  2. The Add <Feature> (Item/Location/ItemLocation, Resources) screen is displayed.

Copying Existing Record Details

  1. To create a new record, in the data table, based on the field values of an existing record, select the check box corresponding to that record.

  2. Click the Copy button.

Modifying Record Details

  1. To modify record details in a data table, select the check box corresponding to the required Record.

  2. Click the Edit button.

  3. The Edit <Feature> (Item/Location/ItemLocation, Resources) screen is displayed.

Deleting Records 

  1. To delete one or more records from an MDM table, select the check box (es) corresponding to the required record (s).
  2. Click the Delete button.
  3. The selected record (s) is deleted and the table editor will be reloaded to display the updated list of records.

Freezing/Unfreezing Columns

  1. The freeze column feature is supported both on table editors as well as workflow editors that display information is in the form of a table (table layout).

  2. To freeze the columns, click on the column header until which you want to freeze and select Freeze from the menu that is displayed.

  3. When you select freeze, all the columns to the left of the selected column (including the selected column) are frozen and do not scroll. A scroll bar appears for all the other columns to the right of selected column. The scroll bar allows these columns to scroll from left to right and vice versa. The number of fields for display remains the same as before the freeze.

  4. To unfreeze the columns, click on any one of the column headers of the frozen columns and select Unfreeze.

Creating User Favorites

  1. Click Create favorite () icon from the right hand top corner of a search screen. The Favorite Manager page is displayed.

Customizing the Table Editor

  1. Click Customize () icon from the right hand top corner of a search screen to sort, re-order and freeze columns. The Customize page is displayed.

Performing a Search 

  1. You can perform a search for records, based on various criteria.

  2. Enter the required values (search parameters) in the search fields, displayed under each column heading.

  3. Click the Search icon.

  4. The search results, based on the parameters specified, will be displayed.

Note: To remove the values specified in the search fields, click on the Clear button.

  1. To save a filter expression created, click the Save filter () icon.

  2. To use advanced filter option click the Advanced filter () icon.

  3. To find out where a particular record is being used, select the check box corresponding to that record, and click the Where used () icon.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the screen.
