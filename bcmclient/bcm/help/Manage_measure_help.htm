Managing Measures

You can search, create, delete and duplicate the measures in the Manage Measures page.

 

 What you can do

Search for Measures

  1. In the Navigation Pad, you must have clicked on the Manage DM Metadata > Measure Maintenance link to view the current screen.
  2. The Manage Measures screen is displayed. 
  3. The value of search string should be name/description of the measure. To narrow your search list you can also specify a measure type (SinglePoint or Bi-Directional) and/or Db Data type (Double or String).
  4. Click on  Show Measures button.
Note: Search is case sensitive. Currently only sub-string search is supported. Wildcard search is not supported.
  1. All the records that match the search parameters that you specified will be displayed in the Measure List table.

Managing Measures

  1. To edit a measure, click on its ‘Name’.
  2. To create a duplicate of an existing measure, select the member using the radio button and click on Duplicate button.
  3. To create a new measure, click on New button.
  4. To delete a measure, select one measure from the list and click on Delete button.
