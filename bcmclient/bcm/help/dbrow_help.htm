Add Item Details Page

The Item Add page helps you to create new Items and save them in the data table. 

 What you can do

Adding New Item Details

  1. In the Item Search Results page, click on the Create button.
  2. The Item Add page is displayed.
  3. Enter appropriate values in all the required fields, and click on Save to add the new Item to the data table.
  4. You can also click on the Save and Return button to save the new item details and return to the Item Search page.

Note: The mandatory fields are marked with a red asterisk (*)
