Managing Mapset Details

You can manage the mapset details.

 

 What you can do

Creating a Mapset

Creating a mapset is a three step definition process.

Basic and Dimensionality

  1. In the Manage Mapsets page, you must have clicked on the New button to view the current screen.
  2. The Mapset Details screen is displayed. 
  3. The name of a new/duplicate mapset can be changed. An existing mapset’s name cannot be changed.
  4. Set the status of a mapset to Active, if you want it to be synchronized into Demand Manager repository.
  5. Use the source and target dimension list boxes to define the mapset’s dimensionality.
  6. Click on Next to move on to the next step of the three step definition process.

Mappings

  1. Existing mappings defined in this mapset are displayed in this table. 
  2. To copy an existing mapping select the mapping, and click on Copy button.
  3. To modify a mapping definition, select the mapping, and click on Modify button.
  4. You can remove one or more mappings. To perform this, select the mapping(s), and click on Remove button 

Note: Copy and Modify are available only for single selection in the table. 

Modifying an existing mapping

  1. This section allows you to add or modify an existing mapping. 
  2. To create a new mapping, just select the level and member. Click on Apply button. 
  3. You can also use the search feature provided to select a member. Click on the icon adjacent to the Member field to do this. If you are modifying an existing mapping, make the changes and click on Apply button.
  4. If you have copied the contents of an existing mapping to create a new one, set the appropriate field values and click on Apply button.

Modifying User Rights

  1. This panel allows you to define, user security for the mapset. 
  2. Select one or more user(s) and/or usergroup(s) from the list box (user groups are differentiated by the suffix “[UG]” in the list box)
  3. Select ‘Read’ and/or ‘Write’ and click on Add button. To remove one or more defined access rights preferences, select the appropriate row(s) and click on Remove button. Each user can either have read or write or {read and write} access on the mapset. Read allows you to view mapsets in the DM planning UI (when this is supported) while Write allows you to modify the mapset’s definition.
  4. Click on Finish button to complete the workflow and save the changes to the database.
