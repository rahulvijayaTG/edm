Mass Update

The Mass Update feature allows you to modify the values of one or more fields across the selected set of records in the MDM table. To perform a "mass update", you must select at least one record by check marking the box (displayed to the left of the table) corresponding to that record. 

Note: Since a mass edit can be across records with disparate values (for the same fields), the current field values are not shown on the screen. 

The Mass Update feature is useful when the value of a particular field (across records in the table) has to be modified, and the value to be entered in that field is the same for all selected records.

 What you can do

Performing a Mass Update

  1. To perform a "mass update", select the required field (s) and enter the new value.

  2. Click on the Save and Return button to update the changes and return to the 'table editor view' screen. This screen will now display the new values in the fields that you modified.

  3. To revert to the original field values, without saving the changes that you made, click on the Cancel button.
