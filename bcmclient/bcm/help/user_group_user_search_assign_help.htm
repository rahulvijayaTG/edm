User Group - Assign Users

The Assign User Group Users page displays a list of users that are not associated with the selected User Group. This page helps you to assign the required (new) user to the selected User group. You can also perform a search for particular user records.

 What you can do

View Available Users' Records

  1. In the User Group Details page, click the Assign button.

  2. The User Search page is displayed, listing all the existing users that are not associated with the selected User Group.

  3. You can view the following user details from this table:

Field Description
Login Name Displays the User's Login Name. Click on the required User Login Name link to view that User's details.
First Name Displays the User's first name.
Last Name Displays the User's second name.
Email Address Displays the User's email address.
User Group Displays the group that a user belongs to.
Organization Name Displays the organization name that a user belongs to.
Status Displays the User status.

  1. Click the Add to Group button to add that User to the User Group and return to the User Group Details page.

  2. Click the Done button to return to the selected User Group Details page.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed on the bottom-left of the page.
