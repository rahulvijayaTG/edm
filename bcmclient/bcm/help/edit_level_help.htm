Edit Level

The Edit Level page helps you to view/edit the selected Level attributes.

 What you can do

View/Edit Level Details

  1. In the Level Search Results page, select the check box corresponding to the Level record that you want to edit and click on the Edit button.
  2. The Level Edit page is displayed. Here, you can make changes only to the editable fields.
  3. Make the necessary changes in the required fields and click on the Save and Return button to update the changes and return to the Level Search Results page.
  4. Click the Cancel button to abort the `edit' operation and return to the previous page, without saving any changes.
