Using the Advanced Filter

The advanced filter option helps you to perform a more complex search, by specifying additional filters. Here, you can customize search filters to your requirements, by using the AND and OR symbols. These user defined filters facilitate a better degree of accuracy.

  What you can do

Performing a Search Using the Advanced Filters

  1. Clicked the Advanced filter icon ().on the top-right corner of the page to view the present page.
  2. The Filter Expression page is made up of three panes - Properties of the Table, Filter Description, and Expression Editor.
  3. Select the required table property from the Properties of the Table pane.
  4. In the Filter Description pane, select the required Operation attribute from the list, and enter an appropriate value in the Filter Value field. Click the OK button.
  5. The expression is displayed in the Expression Editor pane.
  6. Click the AND, OR, or the '()' (braces) buttons in the Properties of the Table pane, and specify required values in the Filter Description pane. 
  7. Click the OK button to append the expression with multiple filter attributes.
  8. To revert to the previously existing expression, click the UNDO button in the Expression Editor pane.
  9. To clear the expression you have created, click the CLEAR button.
  10. To save the new filter expression and apply it to the Search operation, click the Apply and Return button.
  11. To abort the 'filter creation' operation and return to the Search page, click the Cancel button.
Note: The filter specification should be mentioned appropriately. For example,
  • Select the “=” operation to search for the record exactly as entered in the Field Value.
  • Use the braces "(" and ")" to separate sub-expressions within the filter expression.
  • Use the “like” operation to add wildcards like "*" and enter that in the Field Value specification.
