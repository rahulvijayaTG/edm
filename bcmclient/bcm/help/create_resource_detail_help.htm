Create Resource Details Page

The Create Resource Detail page helps you to create a new Resource. 

The Resource Details page displays the Resource Name, Resource Class, Description, Location, Type, and status details fields. 

 What you can do

Create a Resource

The Create Resource Details page displays two areas - Resource Details and General.

In the Resource Detail section of the page, enter appropriate values in the following fields:

Field Description
Resource Name Enter the resource name.
Resource Class Select the required resource class from the list.
Description Enter a resource description.
Location Enter a valid resource location. You can also select a location by clicking on the Location look-up icon.
Status Select the appropriate status from the list.
Type Select the appropriate resource type from the list.

Note: The mandatory fields are marked with a red asterisk (*).

  1. Click the Save button.

  2. The resource detail information is saved and the page is reloaded, displaying the General tab along with three additional tabs - Bill of Resources, Resource Alternates, and Assigned Calendars.

  3. The General section allows you to specify the resource category, sub-category, release fence, release fence uom, number of units, units uom, and lot size details.

  4. Enter appropriate values in all the fields and click the Save button.

Note: You must save the changes in the General tab before clicking on the other tabs. Otherwise, changes made to the fields in this tab will be lost.
