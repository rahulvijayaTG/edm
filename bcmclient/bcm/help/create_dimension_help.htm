Create Dimension

The Dimension Add page helps you to create new Dimension details.

 What you can do

Create New Dimension Details

  1. In the Dimension Search Results page, you must have clicked on the Create button to view the current page.
  2. Here, enter a unique value in the Dimension Name and ID fields.

Note: The Dimension ID field (including all the fields in this page) is a text-only field. Do not specify any numerical or special characters in any of these fields.

  1. Enter a brief description of the new Dimension, in the Description field.
  2. Click on the Save button to save the new Dimension record in the data table. Alternately, you can also click on the Save and Return button to save the new record and return to the Dimension Search Results page.
  3. Click on the Cancel button to abort the `create' activity, and return to the previous page without saving any changes.
