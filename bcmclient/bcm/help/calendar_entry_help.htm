Calendar Entry Page

The Calendar Entry page displays the Calendar details, including calendar Patterns, and Attributes. You can add a new Calendar entry, or modify the existing entry details from here. 

 What you can do

View/Modify Existing Calendar Entry Details

  1. Clicked on the Pattern link in the selected Calendar Details page to view the current page.

  2. This page displays the selected Calendar entry details, including the Pattern and Attribute details. You can modify these details from here.

  3. Make changes to the required fields and click on the Save and Return button to save the changes and return to the selected Calendar Details page.

Add New Calendar Entry Details

  1. Click on the New Entry button in the Calendar Details page to view the current page.

  2. This page helps you to create new calendar entry details including the Calendar Pattern, and Attribute details.

  3. In the Calendar Entry section of the page, enter the required From and To dates in the respective fields (in mm/dd/yyyy format). Alternately, you can click on the Calendar icon () to view the calendar pop-up menu and select the required dates.

  4. Select the appropriate Bucket Size from the list and enter the required Start and End Time in the respective fields.

Note: Depending to the Bucket Size value that you select, the page will reload to display the related Patterns and Attribute fields.

  1. In the Patterns sections of the page, select the radio button corresponding to the pattern that you want to have for the new entry.

Note: If you select the Every radio button, enter the number of days in the field provided. If you select the Every Week On radio button, ensure you select the check box (es) corresponding to the required days of the week.

  2. Click on the Save and Return button to save the new calendar entry and return to the selected Calendar Details page.
