Copy Member

The Member Copy page helps you to create a new Member record, based on an already existing one, complete with all the attributes of the original record.

 What you can do

Copy Existing Member Details

  1. In the Member Search Results page, select the check box corresponding to the Member record that you want to copy and click the Copy button.
  2. The member Copy page is displayed.
  3. In the Level ID field, enter a unique Level ID.
  4. In the Member ID field, enter a unique member ID.
  5. Click the Save and Return button to save the new Member record and return to the Member Search Results page.
  6. At any point of time, to abort the `copy' operation (before performing the `save' operation), click the Cancel button.
