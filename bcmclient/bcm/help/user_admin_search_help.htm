Viewing Users for the selected User Group

The users for the selected user group are displayed in the User Search page.  

 What you can do

The Search Results Table

  1. The Search results table displayed at the bottom of the page, lists various User Details, including the Login name, First name, Last name, E-mail address, User Group, Status, and Organization name.

  2. To view details of a particular User, select the radio button corresponding to that user, and click the User Details button.
    The User Details page is displayed, listing all the details of that user. You can also modify the user details (as required).

  3. Click the Done button to return to the User Group Details page.

Browsing the Search Results

If there are more than 10 records, browse through these records using the navigation buttons (), displayed at the bottom-left of the page.
