How do I ...

Select Search Results

  1. Check the check box adjacent to the ID you want to select.
  2. To download a document, click Download. This launches the File Download function and allows you to select the location of where you want to save the file. The selected order is saved in an XML format.
  3. To save a report, click Save Report. This launches the File Download function and allows you to select the location of where you want to save the report. The columns of the selected order are saved in a CSV format which can be accessed by Microsoft Excel or any other text editor.
