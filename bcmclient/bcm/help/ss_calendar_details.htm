Safety Stock Calendar Page 

The Safety Stock Calendar page helps you to modify, add, and delete safety stock parameters for the selected Item Location. 

This page displays the Item ID, Location ID, Item Description, and the Safety Stock Type details as read-only fields.

 What you can do

Add a New Safety Stock Entry 

  1. In the Item Location Details page, click the Safety Stock Calendar button to view the current page.

  2. Enter an appropriate Start Date (in mm/dd/yyyy format), or click the Calendar icon to select the required date.

  3. Enter an appropriate value in the Min on Hand field.

  4. Click the Add button to add the new record to the data table.

Note: Click the Cancel button to abort the 'add' activity and return to the Item Location Search page.

  1. The new Safety Stock parameters record is displayed in the Safety Stock Calendar Details grid.

  2. Click the Return button to save the new record and return to the Item Location Search page.

Note: Start date is the date from when the specified safety stock quantity should be made available.
         Min on hand is the minimum quantity of the selected Item that must be available at a Location.

Modifying Existing Safety Stock Parameters

  1. In the Safety Stock Calendar page, make the required changes to the Start Date and/or Min on Hand fields.

  2. Click the Update button to save the changes to the record.

  3. Click the Return button to update the changes to the record and return to the Item Location Search page.

  4. Click the Cancel button to lose the changes you made to the record, and return to the Item Location Search page.

Deleting an Existing Safety Stock Parameter Record

  1. In the Safety Stock Calendar detail table, select the check box corresponding to the record that you want to delete.

  2. Click the Delete button.
    The selected safety stock parameter record is deleted.
