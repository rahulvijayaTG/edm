Edit Member

The Edit Member page helps you to view/edit the selected Member attributes.

 What you can do

View/Edit Member Details

  1. In the Member Search Results page, select the check box corresponding to the Member record that you want to edit and click the Edit button.
  2. The Member Edit page is displayed. Here, you can make changes only to the editable fields.
  3. Make the necessary changes in the required fields and click on the Save and Return button to update the changes and return to the Member Search Results page.
  4. Click the Cancel button to abort the `edit' operation and return to the previous page, without saving any changes.
