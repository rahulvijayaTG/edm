Table Editor - Edit Screen

The Edit Screen helps you to modify the selected 'Component' details. 

 What you can do

Modifying 'Component' Details

  1. In the Table Editor, you must have selected the check box corresponding to a component ID/Name that you want to modify and clicked on the Edit button.
  2. The <Component> Edit screen is displayed.
  3. Make appropriate changes in the required fields, and click on the Save and Return button to update the changes and return to the Table Editor screen.

Note: The mandatory fields are marked with a red asterisk (*)
