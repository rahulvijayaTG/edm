Search User Groups

The Search User Groups page helps you to perform a search for the required User Group records.

You can also perform a search by specifying a 'wildcard' character (*), for example, enter "bp*" in the Group Name field. Such a filter will retrieve all the records that have "bp" in their Group Names. 

Note: If you perform a search without specifying any filters in the search fields, the search result that is displayed will list all the available User Group records in the system, including the deactivated groups.

 You can also choose to add a new user group.

 What you can do

Performing a Search for User Groups

You can search for user groups by entering suitable values in the following fields.
Field Description
Name Enter the required user group name.
Show Inactive Select this check box if you want to search for only those user groups whose status is "Inactive".

  1. Click the Search button.

  2. The Search Results grid will display all the user group records that match the search filter (s) you had specified.

The Search Results Grid

The Search Results grid displays the following details:

Field Description
Group Name Displays the group name. Click on the required Group Name link to view that User Group details.
Group Type Displays the group type.
Organization Name Displays the organization name that the user group belongs to.
Status Displays the user group status.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) that you specified, you can browse through them sing the navigation buttons
