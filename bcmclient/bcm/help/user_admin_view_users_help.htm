View User Group Users

Summary information is displayed for each user in the user group retrieved in the search. The search result container contains the generated search result. Apart from the User name specified in the search, the search results display the corresponding First name, Last name-mail address, Organization name, Status and Role. Additional user details can be obtained for a specific user by clicking on the radio buttons to the left of desired user name in the search results and then clicking on the User details option. A user detail screen is then displayed. The search result container also gives the user the ease of scrolling through the pages with the various options near the bottom left corner of the search result next to the jump option

The Search Results container contains the generated output of any search. The Search Result container has the following features:


1.   View details of a desired user

2.   Reset password for any user

3.   Arrange the fields in ascending/descending order.

 To view details of a particular user,

1.       Select the desired user by clicking on the radio button to the left of the user name.

2.       Then select the user details option to go to the user details screen.

To Reset the password

1.       Select the Reset password option

2.       The user will then be mailed a new password, which can be changed and used for further operations.

To arrange the field in ascending/descending order

1.       Click on the desired field and choose from option of ascending or descending order from the pop up list

2.       This will arrange the field elements in either alphabetical order or active/inactive. Note that this arrangement is case sensitive
