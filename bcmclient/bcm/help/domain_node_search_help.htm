Domain Node Search

The Domain Node Search screen primarily helps you to perform a search for required nodes based on specific Dimension, Hierarchy, and Level attributes. It further allows you to select nodes to be either included for access, or excluded to specific User groups.  

 What you can do

Perform a Node Search

  1. In the User Group Domain screen, you must have clicked on the Add button to view the current screen.
  2. This screen helps you to perform a Node Search based on the following criteria:
  • Dimension: From the Dimension drop-down list, select the required Dimension name.
  • Hierarchy: From the Hierarchy drop-down list, select the required Hierarchy name.
  • Level: From the Level drop-down list, select the required Level name.
  1. Select appropriate values in all the above-mentioned fields, and click on the Search button.
  2. The Node Search Results table will display all the node records that match the parameters that you had specified.
  3. Now, select the check box (es) corresponding to the node records that you want to add, and click on the Select and Return button.
  4. This will save your selection and return you to the User Group Domain screen (Included Nodes Tab or Excluded Nodes Tab).
  5. Click on the Cancel button to abort the selection activity, and return to the User Group Domain screen, without saving the selections.
