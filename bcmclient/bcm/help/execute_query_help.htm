Execute Query Page

The Execute Query page helps you to execute the stored queries. 

 

 What you can do

Executing Queries

  1. You must have clicked on the Execute Query button in the Query Search page to view the current page.  

  2. This page helps you to execute the stored queries.

  3. Click Yes in the resulting message box.

  4. The Execute Query page displays the query name and the SQL query string. If any runtime parameters are expected, they are listed in the Parameters table.

  5. Enter the values for each required parameter and click on Execute Query.
    The Query Search Results page shows the results of the query. Click on Export To Excel to export the results to Excel.
