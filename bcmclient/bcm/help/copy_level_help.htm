Copy Level

The Level Copy page helps you to create a new dimension record, based on an already existing one, complete with all the attributes of the original record.

 What you can do

Copy Existing Level Details

  1. In the Level Search Results page, you must have selected the check box corresponding to the Level record that you want to copy, and clicked on the Copy button.
  2. The Level Copy page that is displayed lists the new record with a system-generated Level ID. Delete this value, and enter a unique Level ID.
  3. Enter the Dimension ID in the Dimension ID field.
  4. Enter a brief description of the new Level in the Description field.
  5. Type a unique value in the Logical Table Name field. For e.g, if the Logical Table Name is Item, it’s corresponding Physical Table Name may be MST_ITEM. The Physical Table is present in the database, while the Logical Table is a link to the Physical Table.
  6. Type a unique value in the Logical Column Name field. The Logical Column Name represents the Primary Key Column Name.
  7. Click the Save and Return button to save the new Level record and return to the Level Search Results page.
  8. At any point of time,  to abort the copy operation (before performing the `save' operation), click the Cancel button.
