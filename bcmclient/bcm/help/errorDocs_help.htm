Data Errors Page

The Data Errors page displays a report of the erroneous data loaded into MDM as part of the operational data load workflow.

 What you can do

Searching for Data Errors

You can search for errors based on the Entity Name in the Documents page.
  1. Type the required Entity Name in the Entity Name field and click the Search button.
  2. The Search Results table displays all the error records that match the search parameter that you had specified. Alternatively, you can also perform a wildcard character search (by specifying a ‘*’ in the search field). This will retrieve all the available error records in the system.
  3. To view the error details, click the required Entity Name link. The selected error document details are displayed in the Error Report page.

Data Errors Details

The Error Report page displays information regarding each error record for a given table. It lists the primary keys, the field due to which the error occurred, the validation rule or constraint which failed and the severity of the error. Click the Export to Excel button to download the error details onto an excel spreadsheet.
