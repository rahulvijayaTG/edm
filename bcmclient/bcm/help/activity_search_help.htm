Activity Search

The Activity Search page helps you to add new activities to an existing role, or a new role that is being created.

 What you can do

Perform an Activity Search

  1. In the Roles Details page, click the Add Activities button to view this page.
  2. The Activity Search page is displayed with the Workflow Activity Search tab and the Table Editor Search Activity tab.
  3. In the Workflow Activity Search tab, you can associate workflow activities to the role.
  4. Type the Role ID and Role Name in the respective fields.
  5. Click the Table Editor Search Activity tab.
  6. In the Table Editor Activity Search tab, you can assign permissions for the selected tables.
  7. Select the required Activity and click the Save and Return button to return to the Role Details page.
  8. In the Table Editor Activity Search tab, you can set the following permissions:
    • View - Select this option to view the selected table. You will be able to view the records in the table only if you have enabled the View option.
    • Create - Select this option to create the selected table. You will be able to create records in the table only if you have enabled the Create option.
    • Edit - Select this option to edit the selected table. You will be able to edit records in the table only if you have enabled the Edit option.
    • Delete - Select this option to delete the selected table. You will be able to delete records in the table only if you have enabled the Delete option.
  9. If the displayed list of activities do not meet your requirement, you can perform a search for the specific activity, based on the Activity Name. Enter the required Activity Name in the text box provided, and click on the Search icon/button.

Note: If the displayed table does not list the required activity, you can also browse through the result set using the navigation buttons.
