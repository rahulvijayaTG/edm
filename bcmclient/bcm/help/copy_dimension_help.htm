Copy Dimension

The Dimension Copy page helps you to create a new dimension record, based on an already existing one, complete with all the attributes of the original record.

 What you can do

Copy Existing Dimension Details

  1. In the Dimension Search Results page, select the check box corresponding to the Dimension record that you want to copy, and click on the Copy button.
  2. The Dimension Copy page that is displayed, lists the new record with a system-generated Dimension ID. Delete this value, and enter a unique Dimension ID.
  3. Enter the name of the dimension in the Name field.
  4. Enter a brief description of the new Dimension in the Description field.
  5. Click on the Save and Return button to save the new Dimension record and return to the Dimension Search Results page.
  6. At any point of time, if you want to abort the copy operation (before performing the `save' operation), click on the Cancel button.
