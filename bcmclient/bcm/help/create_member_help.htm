Create Member

The Member Add page helps you to create new Member details.

 What you can do

Create New Member Details

  1. In the Member Search Results page, click  the Create button to view the current page.
  2. Here, enter a valid Level ID, or click on the Level look-up icon () to view the list of Level IDs, from which, you can select the required value, to associate the new member with that Level.
  3. Enter a unique member ID in the ID field.
  4. Enter the name of the new member in the Name field.
  5. Enter a brief description of the member in the Description field.
  6. Type the primary key of the record (in the original table) in the Foreign Key field. (For e.g, Item)
  7. Click on the Cancel button to abort the `create' activity, and return to the previous page without saving any changes.

Note: All the fields in this page are text-only fields. Do not specify any numerical or special characters in any of these fields.

  1. Click on the Save button to save the new Member record in the data table. Alternately, you can also click on the Save and Return button to save the new record, and return to the Member Search Results page.
  2. Click on the Cancel button to abort the `create' activity, and return to the previous page without saving any changes.
