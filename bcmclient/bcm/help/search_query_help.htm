Search Query Page

The Search Query page helps you to perform a Query search based on the Query Name. 

Note: If you perform a search without specifying any search query name, the search results will list all the available records in the system.

 What you can do

Performing a Search

  1. Enter the Query Name.

  2. Click the Search button.
    The search results are displayed in the Search Query column. It includes the details on the user who created the query and details about the last run including the user who executed the query, start time, result and run time.

  3. You can search queries, create, edit or delete queries, execute queries and inspect query execution history from this page.

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, you can browse through these records using the navigation buttons (), displayed at the bottom of the page.
