Mass Update Of Operation Records

The Mass Update Hierarchy feature allows you to modify values for different fields in the Search Operations area of the Operations Search page simultaneously.

 What you can do

Update Records simultaneously

  1. Select the records in the Operation Search page.
  2. Click the Mass Update button.

    The Group Edit Form Contents page is displayed for the selected records.

  3. Select the required properties to be edited.
  4. For the selected properties, enter the new value in the field provided. For e.g, enter a value of 10 in the Rate field.
  5. Click the Save And Return button.

    The selected supply chain records are all updated.

  6. Click the Cancel button to cancel the operation.
