Create New Calendar Details

This page helps you to create a new Calendar and associate it to the selected resource. The Create Calendar Details page also helps you to add new entries to the calendar that you are creating. 

 What you can do

Creating a New Calendar Entry

  1. This page displays a system-generated calendar Name. You can delete this name and specify an appropriate Name for the Calendar you are creating.
  2. The Fields displayed are listed in the table below:
Field Description
Calendar name Enter an appropriate Calendar name.
Description Enter a brief description of the calendar that you are creating.
Category Enter the Calendar category in this field.
Availability UOM Select the required unit of measurement to be used, to determine the availability of the associated resource.
Sub-Category Enter the Calendar sub-category.
Calendar Type Select the appropriate Calendar type, from the drop-down list.
  1. Enter appropriate values in all the above-mentioned fields and click on the Save button. The Calendar Details table is displayed at the bottom of the page.
  2. Click on the Cancel button to abort the 'create calendar' function.
  3. Click on the New Entry button to specify Calendar entry details for the new Calendar that you have created.
  4. Once you have completed entering all the required details in the Calendar Entry page and returned to this page, click on the Save and Return button to save the new calendar record and return to the Edit Resource page, or the Calendar Search page, depending on where you chose to create the Calendar from.
  5. To remove a Calendar Entry from the Calendar Details table, select the corresponding check box and click on the Delete button.
