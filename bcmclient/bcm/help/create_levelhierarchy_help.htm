Create Level Hierarchy

The Levelhierarchy Add page helps you to create new Levelhierarchy details.

 What you can do

Create New LevelHierarchy Details

  1. In the Levelhierarchy Search Results page, click the Create button to view the current page.
  2. Here, enter a valid Hierarchy ID, or click on the Hierarchy look-up icon () to view the list of Hierarchy ID, from which, you can select the required value.
  3. Enter an appropriate value in the Level ID . You can also click on the look-up icon to view the list of Level IDs and select the required value.
  4. Type a rank for the level hierarchy in the Rank field. The order of levels in the hierarchy is defined by the rank. For e.g, a level of rank ‘1’ would be ranked first in the hierarchy.

Note: All the fields in this page are text-only fields. Do not specify any numerical or special characters in any of these fields

  1. Click on the Save button to save the new LevelHierarchy record in the data table. Alternately, you can also click on the Save and Return button to save the new record, and return to the LevelHierarchy Search Results page.
  2. Click on the Cancel button to abort the `create' activity, and return to the previous page without saving any changes.
