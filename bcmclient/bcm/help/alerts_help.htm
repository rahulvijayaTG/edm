Alerts Page

When you log into Master Data Management, the Data Management option is highlighted in the Navigation Pad (left-pane) and the MDM:Alerts page is displayed.

This page is made up of four tabs:

  1. Fatal Alerts
  2. Severe Alerts
  3. Warning Alerts
  4. Information Alerts

Click on the required tab to view the Alerts generated under that category.

The Alerts are generated and listed under the appropriate tabs, depending on the severity of the task and the action required. The most common sources of alerts are staging operations, reflecting problems, moving, or validating data. 

The first three alerts require you to take appropriate actions to resolve the issue (s). Information Alerts provide a confirmation of the tasks that you have completed. For Example, an Information Alert will inform the Administrator of the completion of various phases of the inbound staging process.

Note: You can view these alerts only after running the E2E workflow.

Field Description

Field Description
Alert ID Displays the Alert ID link.
Time Issued Displays the time when the Alert record was generated. You can sort the Alert records in Ascending or Descending order of the time when generated, by clicking on the Time Issued link, and selecting the required order.
Description Displays a brief description of the Alert record.

 

 What you can do

Viewing the Alert details

  1. To view the Alert details, click on the required Alert message link.

Browsing the Alert Records

  1. If there are more than ten Alert records, you can browse these records by using the First, Previous, Next and Last buttons displayed at the left-bottom of the Alerts page.
  2. If you want to go to a specific records page, specify the page number in the text box provided, and click on Jump ().

Deleting the Alert Records

  1. To delete an Alert record, select the check box corresponding to that record.
  2. Click Clear.

Performing a Mass Delete

  1. To perform a "mass delete", select the check box displayed next to the Alert ID column in the grid.
  2. All the Alert records are selected.
  3. Click Clear to delete all the displayed records.
