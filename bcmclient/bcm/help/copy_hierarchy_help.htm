Copy Hierarchy

The Hierarchy Copy page helps you to create a new Hierarchy record, based on an already existing one, complete with all the attributes of the original record.

 What you can do

Copy Existing Hierarchy Details

  1. In the Hierarchy Search Results page, select the check box corresponding to the Hierarchy record that you want to copy and click on the Copy button.
  2. The Hierarchy Copy page that is displayed, lists the new record with a system-generated Hierarchy ID. Delete this value, and enter a unique Hierarchy ID.
  3. Enter the Dimension ID in the Dimension ID field, 
  4. Enter a brief description of the new Hierarchy in the Description field.
  5. Click the Save and Return button to save the new Hierarchy record and return to the Hierarchy Search Results page.
  6. At any point of time, to abort the copy operation (before performing the `save' operation), click the Cancel button.
