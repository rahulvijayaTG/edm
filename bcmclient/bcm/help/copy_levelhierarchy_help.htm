Copy LevelHierarchy

This feature helps you to create a new Levelhierarchy record, based on an already existing one, complete with all the attributes of the original record.

 What you can do

Copy Existing LevelHierarchy Details

  1. In the LevelHierarchy Search Results page, select the check box corresponding to the LevelHierarchy record that you want to copy, and click the Copy button.
  2. The LevelHierarchy Copy page that is displayed lists the new record with a system-generated Hierarchy, and Level ID values. Delete these values and enter unique values in both the fields .
  3. Type a rank for the level hierarchy in the Rank field. The order of levels in the hierarchy is defined by the rank. For e.g, a level of rank ‘1’ would be ranked first in the hierarchy.
  4. Click on the Save and Return button to save the new LevelHierarchy record and return to the LevelHierarchy Search Results page.
  5. At any point of time, to abort the copy operation (before performing the `save' operation), click on the Cancel button.
