Query Details Page

The Query Details page helps you to edit the details of the Query such as Query Name and Query Detail. You can also add or delete parameters in the query.

 

 What you can do

Editing Queries

  1. You must have clicked on the Query Details button on the Query Search page to view the current page.

  2. The Query Details page displays the details such as Query Name and Query Detail. These are required fields.

  3. Modify the query name, if required.

  4. The SQL query string can be edited or replaced. Parameters can be added, edited or deleted. Click on Save or Save And Return to save the query details.
