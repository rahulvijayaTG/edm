Create Calendar Details Page

The Create Calendar Details page guides you through the creation of a basic calendar and the calendar detail entries.

 What you can do

Create Calendar Details

  1. You must have clicked on a Create link in the Calendar Search page to view the current page.

  2. This page helps you to create Calendar details.

  3. You can create the following calendar details:

Field Description
Calendar Name Displays the Calendar name. To modify this field, enter a different, but unique name.
Description Displays a brief description of the calendar. Modify this description, if required.
Category Displays the calendar category. Change the category of the calendar, if required.
Availability UOM Displays the unit of measurement, for the availability of the resource. Change this value by selecting the appropriate UOM from the drop-down list.
Sub Category Displays the calendar sub-category. Change this value if required.
Calendar Type Displays the calendar type. You can modify this value by selecting the appropriate value from the drop-down list.
Generic Displays user specified start, end and available quantity. 

Specialized Calendars

MDM supports two types of fixed bucket calendars: 

  • Fixed Weekly Bucket Calendar

  • Fixed Monthly Bucket Calendar

  1. Enter a value for Calendar Name and select the appropriate Calendar Type from the Calendar Type dropdown.

  2. Check the radio button against “Fixed Monthly Bucket” to create a fixed monthly bucket calendar OR

  3. Check the radio button against “Fixed Weekly Bucket” to create a fixed weekly bucket calendar.

  4. Select a Reference Horizon from the dropdown menu against the selected fixed bucket.

  5. Click on the Next button.

To edit the Calendar details, click Calendar Setup in the breadcrumb and click Save And Return.
