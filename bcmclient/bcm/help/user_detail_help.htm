User details

The User Details page provides general information about the user currently logged in. While some of the fields in this page are displayed as read-only labels, there are a few editable fields where the existing values can be modified.

Note: Not all the fields in this page are editable. The non-editable fields are displayed as read-only labels.

 What you can do

View/Modify General User Information

  1. Click Tools > My Profile.
    The User Details - General Information page is displayed. You can view and modify general user information in the User Details - General Information page. It is mandatory to have proper data in the fields marked with a red asterisk (*).

  2. Modify information in the following fields.

    1. Login Nam - Displays the login name of the user logged in. You can modify this value.

    2. First Name - Displays the User’s First name. You can modify this value.

    3. Last Name - Displays the Last Name. You can modify this value.

    4. Phone and Fax - Displays the user’s contact phone number and fax. You can modify these values.

    5. Email Address - Displays the user’s e-mail address. You can modify this value.

    6. Address Lines 1-3 - Displays the user’s address. You can modify the address fields.

    7. City - Displays the City where the user is located. You can modify this value.

    8. State - Displays the State where the user is located. To modify this value, select the required State code from the list.

    9. Postal Code - Displays the user’s postal code. Enter a different postal code to modify this field.

    10. Country - Displays the Country where the user is located. To modify this value, select the required country name from the list.

    11. Designation - Displays the user’s designation. Select the required value from the list.

    12. Manager - Displays the manager's name for the user logged in. Select the required value from the list.

    13. Absentee - Displays the name of the person who can be assigned this task, in the user's absence. Select the required value from the list.

    14. Locale - Displays the language setting for the logged in user. You can change the Locale setting by selecting the required language from the list.

  3. To reset the changes, click the Reset button.

  4. All the user details will be reset to the values that existed before changing them.

  5. Click the Update button.

  6. To change the password, click the Change Password button.

  7. The Change Password page is displayed.

  8. You can change the password in the Change Password page.

  9. Click the Deactivate button to deactivate the user, if required.
