Role Details

The Roles Details page helps you to view/modify the role ID, and name details, including the activities associated with the selected role. 

 What you can do

Viewing/Editing Role Details

  1. In the Manage Roles Search Results page, click the required Role Name link to view the Role Details page.
  2. The Role ID and Role Name for the selected role and the list of activities associated with it are displayed. 
    The Role Details page has 2 tabs, Workflow Role Details and Table Editor Role Details. 
  3. Make the required changes to the Role ID and Role Name details.
  4. In the Workflow Activity Search tab, you can associate workflow activities to the role.
  5. To add workflow activities to the role, click the Add Activities button. 
    The Activity Search page is displayed.
  6. Select the required activity and click the Save and Return button.
  7. To remove a workflow activity from the role, select the required activity name and click the Remove Activities button.
    The selected workflow activity is removed.
  8. Select the Table Editor Activity Search tab. 
    In the Table Editor Activity Search tab, you can assign permissions for the selected tables.
  9. Click the Add Activities button. 
  10. For the selected table, you can set the following permissions: 
    1. View - Select this option to view the selected table. You will be able to view the records in the table only if you have enabled the View option. 
      Note:       Ensure that you select the View option for a table. If you do not select the View option for a table, you will not be able to create, edit, and delete items in that table.
    2. Create - Select this option to create the selected table. You will be able to create records in the table only if you have enabled the Create option.
    3. Edit - Select this option to edit the selected table. You will be able to edit records in the table only if you have enabled the Edit option.
    4. Delete - Select this option to delete the selected table. You will be able to delete records in the table only if you have enabled the Delete option.
  11. Click the Save As New button to save the existing role as a new role.
