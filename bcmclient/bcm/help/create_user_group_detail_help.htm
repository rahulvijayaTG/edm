Create User Group Details

The User Group Details page helps you to create a new User Group. 

 What you can do

Creating User Group Details

  1. Click the Add New User Group button in the User Group Search page to view the User Group Details page.

  2. This page helps you to create new User Group details.

  3. The General Information section displays the following details:

Field Description
Group Name Enter a unique Group Name. 
Description Enter a brief description of the new User group. 
Role Details The Role Details section of the page displays a list box. This lists the currently assigned roles, and all available roles in the respective boxes. Here, you can add more roles to the selected user group, and/or delete the existing Role (s).

Note: One user group can comprise multiple Roles. 
Organization Displays the organization name as a read-only label. You cannot modify this information.
Type Displays a default Group type. Select the required Group Type, from the drop-down list to modify this value.

The Assignable Roles list box is displayed, only when you save this record. Initially, this list box will not list any values. Click on the Edit List button to add the required role templates to the new User Group. In the User Group Profile page that is displayed, select the required Roles Template and click on the Done button.
Users The View, Assign, and Add New buttons will be enabled only when you save the user group. Create a new user or assign an existing user to the selected user group.
  • To view the Users belonging to the selected group, click the View button. The View User Group Users page is displayed, listing all the users for the selected Group. 
  • To assign new users to the selected group, click on the Assign button. The User Search - Search Results page is displayed. Select the User(s) to be added to the group and click the Add to Group button. 
  • To create new users, click the Add New button. The User Details - General Information page is displayed. Click the Save button to add the new user to the selected user group. The newly created user is automatically added to the user group.

  2. Click on the Cancel button (before performing an 'Update' function), to return to the User Group Search page, without saving the changes that you made to the selected Group record.

Activating/Deactivating a Group

  1. If the new user group is in the 'Inactive' status, the Activate button is displayed. Click on the Activate button to change its status to 'Active'. A status message confirming the operation is displayed below the User group Details section heading.

  2. To change the group status to 'inactive', click on the Deactivate button.

The Save as New Feature

  1. The 'Save as New' feature is very similar to the Copy function in MDM.

  2. You can create a new User Group with the same attributes, using this feature.

  3. Ensure that you enter a unique name in the Group Name field.

  4. Click the Save as New button.

  5. The page is reloaded, and the new User Group is displayed, with the same details as that of the originally selected one.
