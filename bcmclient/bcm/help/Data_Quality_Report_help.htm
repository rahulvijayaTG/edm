Data Quality Report

Data Quality dashboard is the front end to monitor data quality of enterprise data based on predefined set of business and data rules.

 What you can do
 

  1. In the Data Quality Report page, select the required Source and Entity from the list and click Submit.

    The Data Quality Report page is displayed.

  2. By default the Quality Rule Report tab is selected. The Quality Rule Report displays all the Quality Rules for the selected source and entity.

  3. Click on the Quality Severity Report tab.

  • Severity Weight: A severity weight of 5 is considered more severe than a severity weight of 3.

  • Total Possible: This field specifies the total possible errors allowed.

  • Occurrence: This field specifies the errors occurred in this report.

  1. Click on the QualityTrend Report tab.

    When this tab is clicked first time it displays all the Report ID’s with the DQ score and Status of the report. To search for Reports within a date range, type a Date Range or click on the Date Picker to select a particular date.

  1. Click on the Quality Report By Entity tab.

    This tab displays the top five High Data Quality Entities to the left and the top five Poor Data Quality Entities to the right with the DQ Score of each Entity.
