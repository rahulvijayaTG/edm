Where Used

The Where used option helps you to view where the selected record is used in the supply chain.

  What you can do

    Performing a Search Using the 'Where Used' Feature

  1. Select the check box corresponding to the required record.

  2. Click the Where Used ()icon.
    The Where Used page is displayed for the selected record.

  3. The page that is displayed lists the location (s) where the selected record has been used in the supply chain.

  4. Click the Return button to return to the Search page..
