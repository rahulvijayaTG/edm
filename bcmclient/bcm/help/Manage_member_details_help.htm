Managing Member Details

You can create and rename, merge and assign parents to the members in the Member Detail page.

 

 What you can do

Creating a Member in the Database

  1. In the Manage Members page, you must have clicked on the New button to view the current screen.
  2. The Member Detail screen is displayed. 
  3. For a new or duplicate member the Name field is open for editing. A new or duplicate member needs to be saved before parent assignment/move operation on it can be executed. A new or duplicate member’s status is always unassigned. The status of a member is automatically controlled by the system.

Recoding/Renaming a Member

  1. For an existing member, the Name field is locked to prevent accidental changes. 
  2. Unlock the field by clicking on the lock icon, and make the change.
  3. Click on Save button to commit the change to the database.

Assigning Parent(s) to a Member

  1. To assign a parent to the member, select the appropriate row in the Member Parent Assignment table, and click on Show Parents button.
  2. Select one parent from Valid Parent Members table and click on Assign button. The changes are saved in the database immediately.

Moving a member from one parent to another

  1. Select the ‘from’ parent in Member Parent Assignment table, click on Show Parents button.
  2.  If the valid parent members list is non-empty, select an appropriate parent and click on Move button. The changes are saved in the database immediately.

Merging a Member with another Member at the Same Level

  1. Click on Merge button.
  2. The Merge Members page is displayed where you can complete the operation.
  3. Since you navigate to this page from Member Details page, you will not be able to change the dimension or level or member name.
  4. You can search by name or description, if you do not know the exact name of the “Merge-to” member.
  5. Select your “Merge-to” member and click on Save button to commit to the database.
