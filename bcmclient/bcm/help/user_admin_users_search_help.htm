User Search page

This page helps you to perform a search for User records, by specifying various search criteria. You can perform a search by either specifying a valid login name (user name), or a wildcard character (*), for example, “bp*”. 

Note: If you perform a search without specifying any criteria in the search fields, the search results will list all the available users in the system. 

The Search Results table will provide a summary of each user record, including Login name, First name, Last name, E-mail address, User Group, Status and Organization name.  

 What you can do

Performing a Search

  1. You can search based on Login Name, User Group, First Name, and Last Name.

  2. Enter a valid login name or enter a wildcard character (for example, "bp*"), in the Login Name field.

  3. Select the Show Inactive check box, if you want to search for Users that are in the "Inactive" state.

  4. Click the Search button.

  5. All the records matching the parameters that you had specified will be displayed in the search results table.

The Search Results Table

  1. The Search results table displayed at the bottom of the page, lists various User Details, including the Login name, First name, Last name, E-mail address, User Group, Status, and Organization name.

  2. To reset the password of a particular user, select the radio button corresponding to that user record and click the Reset Password button. The new password will be sent to that user through email.

  3. To view details of a particular User, select the radio button corresponding to that user, and click the User Details button.

  4. The User Details page is displayed, listing all the details of that user. You can also modify the user details (as required).

Browsing the Search Results

If there are more than 10 records that match the search filter (s) you had specified, browse through these records using the navigation buttons (), displayed at the bottom-left of the page.
